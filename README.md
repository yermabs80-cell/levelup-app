# Ethos Tracker

Трекер личного развития: квесты, ранги, четыре пути роста, финансы и помодоро-таймер.
PWA без сборки — обычные ES-модули, открывается в браузере как есть.

## Запуск

```bash
npm install
npm start          # http://localhost:4173
```

Открывать именно по `http://localhost`, а не двойным кликом по `index.html`.
Google запрещает вход со страниц `file://`, а модули и service worker там тоже не работают.

```bash
npm test           # 22 теста ядра
npm run lint
```

## Как считается опыт

Опыт — **производная от журнала выполнений**, а не накопительный счётчик.
Каждая отметка пишется как `completions[дата][ключ квеста]`.

Отсюда три следствия:

- удалить квест и добавить заново не даёт повторный опыт — ключ за этот день уже занят;
- серия восстанавливается сама, даже если приложение не открывали;
- слияние двух устройств не удваивает опыт: одинаковые ключи схлопываются.

Одна завершённая сессия помодоро — 20 XP в дисциплину. Пропуск фазы опыта не даёт.

## Хранение

| Что | Где | Почему |
|---|---|---|
| Прогресс, квесты, финансы | localStorage | небольшой объём, синхронный доступ |
| Фотографии | IndexedDB | base64 переполнял квоту localStorage |
| Облачная копия | Firestore | без фотографий — они остаются на устройстве |

Повреждённый JSON не роняет приложение: старое значение сохраняется в резервный
ключ, а приложение стартует с чистого профиля.

## Синхронизация

Живая подписка `onSnapshot`: изменение на одном устройстве видно на другом сразу.
Конфликты разрешаются слиянием, а не «кто последний записал» — расхождение
системных часов не приводит к потере данных.

## Помодоро

Два режима: **25/5** и **50/10**. После четвёртой сессии — длинный перерыв.

Отсчёт ведётся от меток времени, а не вычитанием по тику: в фоновой вкладке
браузер душит таймеры до одного срабатывания в минуту, и наивный подход отстал бы
на десятки минут.

Пять фоновых звуков (дождь, лес, волны, ночь) синтезируются из шума прямо
в браузере — ни одного мегабайта загрузок, бесшовное зацикливание, работает офлайн.
